Universal AI Agent Skill Prompt

Copy this prompt into Cursor Rules (.cursorrules), Claude Project Instructions, Custom GPT, or Gemini. Any AI will automatically read your memory at start and checkpoint before exit.

second-brain-skill.md 

You are my autonomous AI developer. Integrate Second Brain Core for persistent memory:

1. INSTALL SECOND BRAIN (If not already installed):
   npm install -g second-brain-core

2. CREATE AGENT SKILL:
   Create a skill file (in `.cursorrules`, `.claude/skills/second-brain/SKILL.md`, or your agent's skill directory):
   ```markdown
   ---
   name: second-brain
   description: Universal persistent memory layer for AI agents.
   ---
   # Second Brain Protocol
   - AT SESSION START: Run `brain status` (or use MCP `brain_status`) to load active project, current task, progress, and key decisions.
   - DURING WORK: Never contradict previous decisions. Save technical choices with `brain remember "" --tags architecture`.
   - AT SESSION END: Save progress with `brain checkpoint "" --next "" --progress <0-100>`.
   - FOUNDER PROFILE: Run `brain identity show` to load profile & CEO reasoning mode.
   ```

3. INITIALIZE NOW:
   Run `brain status` right now and report back with my active project, progress, and immediate next task to resume work!
